# RESUME CONTENT - Tamil Nadu Crop Prediction System

## Machine Learning & Model Development
• Developed Random Forest regression model achieving 99.71% R² Score on crop yield predictions with 11 engineered features (district, season, area, rainfall, temperature, humidity, soil type, NPK levels, pH) trained on 11,936 agricultural records from Tamil Nadu. Implemented comprehensive data preprocessing pipeline including feature scaling, label encoding, and automated dataset merging from multiple sources with different formats. Achieved production-ready validation metrics: RMSE of 865.49 and MAE of 31.55, demonstrating exceptional model accuracy for real-world agricultural forecasting applications.

• Built end-to-end machine learning workflow using scikit-learn including data loading, feature engineering, model training with Random Forest ensemble (100 estimators), and joblib-based model serialization. Implemented cross-validation with proper train-test split (80/20) for robust performance evaluation. Created automated accuracy metrics generation with detailed performance reports (precision, recall, F1-score) and feature importance analysis for interpretable model decisions and stakeholder communication.

## Backend Development & API Design
• Built comprehensive RESTful API using Flask 3.0.2 with 15+ endpoints handling crop recommendations, yield predictions, pesticide suggestions, user authentication, and weather integration. Implemented JWT-based authentication system with secure token validation ensuring user session security across the application. Designed normalized SQLite database schema supporting users, crops, historical predictions, pesticide data, and weather records with proper relational integrity and query optimization for efficient data retrieval.

• Developed modular backend architecture with utility separation (model_utils.py, pesticide_utils.py, weather_utils.py, knowledge_base.py) enabling maintainable codebase and scalable feature additions. Implemented CORS-enabled API with comprehensive error handling, request validation, and automated data pipeline for merging crop production, rainfall, and synthetic soil/weather datasets from multiple CSV sources with different formats and encoding challenges.
